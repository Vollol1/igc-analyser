## Release notes (Markdown)

```markdown
## What's new in v1.0.0

This release prepares the repository for a public GitHub release. The core
functionality (listing, downloading, importing and exporting IGC flight tracks)
remains unchanged, but the project is now cleaner, brand-neutral and safer to
share.

### Highlights

- **Prominent disclaimer** in `README.md` and as a non-blocking startup message
  in `igc_extractor.py`, `list_flights.py` and `download_igc.py`. The tool is
  unofficial, uses your own credentials, and may result in an account ban by the
  platform operator. Use at your own risk.
- **No personal defaults anymore**: `export_flight_map.py` and `export_igc_zip.py`
  no longer contain a hard-coded pilot name. Set the pilot/sender name via the
  `PILOT_NAME` environment variable or override it with `--pilot-name` (or
  `--sender` for the ZIP export).
- **Brand-neutral descriptions**: CLI help texts and docstrings now refer to a
  "supported flight-data platform" instead of naming the platform.
- **Documentation clean-up**: absolute local paths in runbooks and notes were
  replaced by relative `./scripts/...` commands. A new compact
  `docs/runbooks/quickstart.md` is available.
- **CI scaffold**: `.github/workflows/ci.yml` runs `py_compile` on every script
  and smoke-tests all `--help` outputs across Python 3.10, 3.11 and 3.12.

### Full changelog

See [CHANGELOG.md](https://github.com/fknab/igc-analyser/blob/main/CHANGELOG.md).

### Compatibility

- Python 3.10+
- Requires `requests`, `beautifulsoup4`, `lxml`; `reportlab` for PDF export.

### Usage

1. Clone the repository.
2. `python3 -m venv venv && source venv/bin/activate && pip install -r requirements.txt`
3. Copy `.env.example` to `.env` and add your credentials.
4. Run `./scripts/igc_extractor.py --flights 10` or follow
   `docs/runbooks/quickstart.md`.

### Disclaimer

`igc-extractor` is an **unofficial, community-built tool**. It is **not**
affiliated with dhv-xc.de, the DHV e.V. or its service portal. The tool logs in
with your personal credentials and downloads **only your own flights**. Usage is
at your own risk; an account ban or other sanctions by the platform operator are
possible.
```
