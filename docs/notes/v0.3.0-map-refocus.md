# v0.3.0 Refokussierung auf interaktive Karte

## Hintergrund

Ursprünglich war v0.3.0 als Release für einen dedizierten **Höhenflug-Nachweis** geplant: ein IGC-Export mit Filter nach Mindesthöhe, speziellen Views und ggf. zusätzlichen Begleitdokumenten.

Im Verlauf der Planung zeigte sich, dass die interaktive Kartenvisualisierung der importierten Flüge einen größeren und unmittelbaren Mehrwert bietet und technisch gut in das bestehende Datenmodell passt.

## Entscheidung

v0.3.0 wird neu fokussiert auf:

- **Interaktive IGC-Flugkarte** als eigenständige HTML-Datei.
- Parsen der B-Records aus den lokalen IGC-Dateien.
- Leaflet/OpenStreetMap-basierte Darstellung von Startplatz-Markern, Tracks und Statistiken.
- Umschaltbare Layer (Kategorie, Startplatz, Flugjahr, Gleitschirm).

Der Höhenflug-Nachweis wird nicht verworfen, sondern als **optional / zurückgestellt** markiert und in `docs/ROADMAP.md` unter `[Unreleased] / Optional` vorgemerkt.

## Konsequenzen

- `docs/ROADMAP.md`:
  - `[Unreleased]` konzentriert sich auf Testsuite, Robustheit und Datenqualität.
  - `v0.3.0` enthält ausschließlich das Kartenfeature.
  - `v0.4.0` konzentriert sich auf „Import aus weiteren Quellen“ und ggf. erweiterte Visualisierung / 3D.
  - Höhenflug-Nachweis ist kein fester Bestandteil mehrerer Releases gleichzeitig.
